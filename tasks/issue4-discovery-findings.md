### 6. Summary: Why "Alphabetical Noise" Occurs

1. **No Score Integration:** SEO pages do not fetch or use PropertyIQ scores to rank related markets.
   - Backend provides ranking API and RPC, but frontend only calls them for interactive dashboards.

2. **Static Slug Data Order:** METRO_SLUG_DATA and COUNTY_SLUG_DATA are generated in alphabetical order by name.
   - Filtering preserves this order → Austin metro shows all TX metros starting with A, B, C...

3. **No Distance Calculation:** Slug data lacks latitude/longitude, so geographic proximity is impossible to compute.
   - Backend geographies table has lat/lon, but it's not exported to frontend slug data.

4. **No Adjacency Mapping:** No geographic_adjacency or metro_neighbors lookup table exists.
   - Would require either distance calculation or explicit mapping.

5. **Arbitrary Slice Limit:** Hard-coded limits (5 metros, 6 counties, 6 ZIPs) hide the full alphabetical list but don't reorder results.
