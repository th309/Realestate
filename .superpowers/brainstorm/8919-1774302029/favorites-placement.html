Where should favorites appear on the graphs page?

Pick the placement that feels most natural without being obtrusive. All options let you set a favorite as "Main" or "Compare".

A

Inside the Search Dropdown

When you click into the market search bar, your favorites appear as a "Favorites" section above the search results. Selecting one gives a small popover: "Set as Main" or "Set as Compare". Zero new UI — lives entirely inside the existing search flow.

Pros

  • No new UI footprint — fits inside existing search
  • Discoverable when you're already selecting a market
  • Main/Compare intent is explicit per click

Cons

  • Must click into search to see favorites
  • Not visible at a glance
B

Compact Star Row Below Header

A thin row of favorite chips sits between the header search bar and the chart. Each chip shows name + score. Click a chip → small "Main | Compare" popover. Scrollable if many favorites. Collapsible with a toggle.

  • Favorites always visible at a glance
  • One-click access (click chip → popover → Main/Compare)
  • Scrollable + collapsible = non-obtrusive

Cons

  • Takes ~32px of vertical space
  • Slightly redundant with search bar above
C

Sidebar "My Markets" Section

Add a collapsible "My Markets" section to the existing sidebar (desktop) that lists favorites. Each has "Set as Main" / "Set as Compare" actions on hover. On mobile, accessible via the bottom sheet.
