How it works across zoom levels

Zoom 3-4 (Full US)

Large states: full name + value centered
Small NE states: leader lines to Atlantic with full name + compact value

Zoom 5-6 (Regional)

Leader lines fade out. Labels transition to centered on state as states get larger on screen. Abbreviations expand to full names.

Zoom 7+ (Close-up)

All labels centered with full names and full values. No leader lines needed — states are large enough to contain their labels.

Implementation Considerations

What's straightforward
  • Polylabel for all state centroids
  • Area-based "is this state small?" detection
  • Zoom-dependent text switching (Mapbox expressions)
  • Leader line layer (Mapbox line source)
Needs careful design
  • Computing offset positions so callouts stack neatly (not overlapping)
  • Leader lines must connect to the right anchor point on each state
  • Smooth fade transition between leader-line and centered modes
  • Handling edge cases: Hawaii, Alaska (already off-screen?)

Quick question

One design detail to settle

A

Pill/Badge style callouts

Semi-transparent dark pill with white text (as shown in mockup above). Clean, modern, doesn't compete with the choropleth colors.

B

Plain text with halo

Same style as the large state labels — white text with a halo. Consistent with existing labels, but might be harder to read over the ocean background.

C

Color-matched pills

Callout pill background matches the state's choropleth color. Creates a visual link between state and its label, but busier.
