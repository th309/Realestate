# PropertyIQ GA4 Activation Funnel — Daily Tracking

Auto-generated by a scheduled daily check (`scripts/analytics/daily-funnel-check.ps1`, Windows Task Scheduler task `PropertyIQ-Daily-Funnel-Check`, runs ~7:30am local). Each run appends a new dated entry **above** this line, comparing against the most recent prior entry. Oldest entries are pruned once there are more than 30.

Funnel: **Visited site → Started sign-up form → Completed sign-up → Started trial** (GA4 events `session_start` → `form_start` → `sign_up` → `trial_start`), measured over the trailing 8 days to avoid the Jun 10–23 bot-storm skew documented in project memory. `purchase` is tracked separately since it's checkout-triggered, not part of the organic funnel.

Do not hand-edit old entries — just let the daily job append. If a day's run fails (e.g., API/auth error), it's fine to have a gap; the next run just compares against the last entry that succeeded.
