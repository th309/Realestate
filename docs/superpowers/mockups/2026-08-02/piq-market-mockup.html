What changed, and why

  1. Collapsed two chrome rows into one control bar. The live page stacks a SCOPE row and a METRIC row above the content, pushing the KPI tiles to 260px down the viewport. Scope breadcrumb, metric chips and the State/Metro/County/ZIP segmented control now share a single sticky bar under the app bar.
  2. Every KPI tile now says what the metric is. Live tiles read "PIQ SCORE 50 ▲ 0.0 pt" with no explanation — and 50 is not a neutral midpoint, it is the market's state average. Each tile gained an 11px caption, and the score tile states the 50 = state average baseline.
  3. Fixed the days-on-market delta polarity. The live page paints "DAYS ON MKT 57 d ▼ 27.3%" red on both the explorer and the detail page, because it colours purely by sign. Falling days on market is a positive input to the PropertyIQ Score (the formula subtracts z(median_days_on_market)), so it is green here. Metrics with no defined polarity — active listings, median rent — are neutral slate instead of being force-coloured.
  4. Confidence is labelled as data quality, not a verdict. The explorer shows five green stars and "100%" with no caption, which reads as a five-star rating of the market. It is now an "A · 100%" grade chip with the line "how complete the inputs are, not a grade of the score", matching how the detail page already words it.
  5. Momentum-mix denominator is exposed. The card header says "Momentum mix · 925 metros" while the page context line right above says "935 metros" — 373 + 189 + 363 = 925, so ten metros carry no momentum bucket. The denominator now sits in the card header as a labelled chip so the gap is visible rather than buried.
  6. The compare tray is no longer hidden. Clicking "+ Compare" flips the button to "✓ Pinned" and silently injects a "Compare pinned markets" panel roughly 900px further down the page, below the three-up row — with no scroll, toast, or count. The tray now carries a "1 pinned" label and an explicit empty slot inviting a second market.
  7. Rankings became a real table. Live rows are stacked flex divs, so the score, momentum label and sparkline never line up on a vertical axis. It is now a proper table with uppercase micro-label headers, right-aligned tabular-mono score badges, and a named "24-mo score trend" column — the sparkline column on the live page has no header at all.
  8. Scatter axes carry an honesty note. The live chart plots 935 bubbles sized by inventory; only 16 metros had a readable score and median value, so the mockup plots exactly those and says so inside the plot rather than faking a density cloud.
  9. Both PropertyIQ Takes are shown side by side. The detail page hides one behind the Homebuyer/Investor toggle, which conceals that they disagree — the investor take says inventory is up 25.7%, the homebuyer take says it surged 133.8%, for the same market and month. Showing both makes the contradiction visible instead of sequential.
  10. Numbers are one monospace tabular system. Scores, dollar values, deltas, dates and CBSA codes all use the mono stack with tabular figures and a true minus sign, so the ranking column and the mover deltas align vertically — on the live page mixed proportional and mono numerals make the −65.0 / −72.0 / −83.0 column ragged.
