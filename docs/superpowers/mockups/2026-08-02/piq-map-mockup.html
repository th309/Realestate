What changes, and what doesn't

Untouched: the Mapbox canvas, choropleth fills, the seven-colour violet-to-red scale, the baked-on state labels and values, zoom and pan. That includes the East Coast label stack — nine states rendering as a text column in the Atlantic is Mapbox label placement, so it stays with the rest of the map.
  1. Two nav bars became one. The light top nav is replaced by the same dark app bar the analyzer, screener, reports, and market pages use. The breadcrumb, hamburger, search, and geography pills collapse into one control row.
  2. The left icon rail is gone. Home / Maps / Analyzer / Markets / Graphs / Reports / About Us / Pricing duplicated the top nav — two navigation models competing on one screen. Removing it returns 64px and leaves a single way to move between tools.
  3. The metric picker moved into the bar. One button showing the active metric and its category, opening the full catalogue. The seven categories and their question subtitles all survive in the sidebar.
  4. The legend is docked. It floated on the map over the Pacific with a "No data available" checkbox inside it. It is now a compact scale in the map header, with the no-data key on the same line.
  5. The score card says why it is empty, and offers a way out. It currently shows a grey ring reading "Select a region to see scores", which is ambiguous at the State level — a user can click every state on the map and never get a score. There is no state-level PropertyIQ Score: the geography enum is metro, county, and ZIP, and 50 is the calibration point against a state average, not a score a state has. The card now states that plainly and offers the three geography levels that are scored. At Metro, County, or ZIP it behaves as it does today and fills on selection.
  6. Table View stopped floating. It was an orphan pill in the bottom-right corner; it is now a Map/Table segmented control in the bar, next to the thing it switches.
  7. Sidebar categories use the shared row pattern — coloured Lucide icon tile, label, question subtitle — the same unit the other tools use for grouped navigation. Same content, same order.
  8. The footer strip is kept, restyled to match. Methodology, Data Sources, About, and the disclaimer all remain.
