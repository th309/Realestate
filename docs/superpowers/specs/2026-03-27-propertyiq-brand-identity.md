## 2. Logo System

### 2.1 Primary Logo — P Monogram + Wordmark

**Logomark:** Stylized "P" in a rounded square (Google-style app icon shape, `rx: 14` at 64px) with green data nodes suggesting network intelligence.

- Background: Indigo `#3949AB`
- P letterform: White
- Data nodes: Green `#00C853` (two nodes, bottom-right, descending opacity)

**Wordmark:** "Property**IQ**" in Roboto Bold.

- "Property" in Deep Indigo `#1A237E`
- "IQ" in Primary Indigo `#3949AB`
- Letter-spacing: -0.5px

**Full lockup:** Logomark left, wordmark right, vertically centered. Optional tagline below wordmark in Roboto Regular 13px, color `#5C6BC0`.

### 2.2 PIQ Shortmark

**Design:** Bold "PIQ" text in white (Roboto 800) on Indigo `#3949AB` rounded square, with ascending data dots beneath the text.

- Dots ascend left to right: `#7986CB` → `#C5CAE9` → `#00C853` → `#00C853` (0.7 opacity)
- Conveys upward trend / growth

**Use cases:** Favicon, app icon (192px, 512px), social media avatars, watermarks, email signatures.

### 2.3 Logo Variants

| Variant            | Use Case                                      |
| ------------------ | --------------------------------------------- |
| **Full lockup**    | Website header, pitch decks, business cards   |
| **Stacked lockup** | Square formats, slide title cards             |
| **PIQ shortmark**  | Favicon, app icon, social avatars, watermarks |
| **Wordmark only**  | When logomark is already visible nearby       |
| **Logomark only**  | App icon in tiny spaces, loading screens      |

### 2.4 Logo Usage Rules

- **Clear space:** Minimum padding = 50% of logomark width on all sides
- **Minimum size:** Logomark: 24px. Full lockup: 120px wide
- **Backgrounds:** Use on white, light gray, or deep indigo. Never on busy photos without overlay.
- **Don't:** Stretch, rotate, recolor, add shadows, use low-res versions, or place on low-contrast backgrounds

## 5. Brand Voice & Tone

### 5.1 Voice Attributes

| Attribute          | Description                                                        |
| ------------------ | ------------------------------------------------------------------ |
| **Confident**      | We know our data. State findings directly, not tentatively.        |
| **Conversational** | Like a knowledgeable friend, not a textbook or sales pitch.        |
| **Data-First**     | Lead with specifics — numbers, percentages, trends — not opinions. |
| **Accessible**     | Explain complex concepts simply. No unnecessary jargon.            |
| **Actionable**     | Always point toward a next step or decision.                       |

### 5.2 Writing Guidelines

| Do                                                  | Don't                                        |
| --------------------------------------------------- | -------------------------------------------- |
| "The data shows 12% rent growth in this metro"      | "Our proprietary algorithm detected..."      |
| "Dallas-Fort Worth scored 78 — strong fundamentals" | "This is an amazing investment opportunity!" |
| "Explore this market"                               | "Buy now!" / "Don't miss out!"               |
| "B-level confidence — good data, rental comps thin" | "We're not totally sure about this one"      |
| "Your Market IQ report is ready"                    | "CONGRATULATIONS on your new report!"        |

### 5.3 Terminology

| Use This            | Not This                 |
| ------------------- | ------------------------ |
| Market IQ Score     | Rating / Grade / Rank    |
| Confidence level    | Accuracy / Trust score   |
| Market intelligence | Market report / Analysis |
| Geography / Market  | Area / Zone / Region     |
| Data coverage       | Data availability        |

## 8. Design System Alignment

This brand identity is built on **Material Design 3 (M3)** principles. The indigo palette maps to M3's tonal palette system:

- **Primary tonal range:** `#1A237E` (tone 10) → `#3949AB` (tone 40) → `#5C6BC0` (tone 60) → `#C5CAE9` (tone 90) → `#E8EAF6` (tone 95)
- **Shape:** M3 Medium (12px radius for cards), M3 Full (pill for buttons/chips)
- **Elevation:** Surface tones + shadow per M3 spec, not glassmorphism
- **Motion:** M3 Standard Easing, 200ms (short), 400ms (medium), 600ms (long)
- **Icons:** Material Symbols (Rounded)

The app's existing `globals.css` CSS variables should be updated to reflect this indigo palette, replacing the current M3 default purple (`#6750A4`).
