# PropertyIQ Validation Data Dictionary

This document defines every metric used in the validation report, where it comes from, and what it means.

---

## Source Files

### validation_results_state.json

Generated by `scripts/analysis/validate_scores.py --benchmark state`

**Structure:**
```json
{
  "metadata": {
    "generated_at": "ISO datetime",
    "geo_level": "metro|county|zip",
    "data_period": {"start": "date", "end": "date", "n_months": int},
    "total_observations": int
  },
  "results": [
    {
      "score_type": "homeready|investoredge",
      "benchmark": "state",
      "target_column": "excess_state_3y|excess_total_state_3y",
      "n_total": int,
      "n_with_target": int,
      "insample": { ... },
      "oos": { ... },
      "time_stability": { ... },
      "calibration": { ... }
    }
  ]
}
```

### optimized_weights.json (and per-geo variants)

Generated by `scripts/analysis/optimize_weights.py`

**Structure:**
```json
{
  "score_type": "homeready|investoredge",
  "geo_level": "metro|county|zip",
  "formula_version": "v2.x",
  "target": "excess_vs_state_3y|...",
  "stable_features": [
    {"name": "metric_name", "mean_coef": float, "direction": 1|-1, "weight": float}
  ],
  "summary": {
    "n_windows": int,
    "n_test": int,
    "avg_test_ic": float,
    "avg_test_quintile_spread": float,
    "avg_test_hit_rate": float,
    "bootstrap_significant": bool,
    "bootstrap_ci": [float, float]
  },
  "window_results": [
    {
      "window": int,
      "train_period": "date to date",
      "test_period": "date to date",
      "n_train": int,
      "n_test": int,
      "test_ic": float,
      "test_quintile_spread": float,
      "test_hit_rate": float,
      "pred_test": [float],
      "y_test": [float],
      "test_quintile_table": [
        {"quintile": 1, "avg_score": float, "avg_excess": float, "n": int, "beat_rate": float}
      ]
    }
  ]
}
```

## Metric Definitions

### In-Sample Metrics

All in-sample metrics are computed by `validate_scores.py` across ALL scored outcomes where 3Y returns are available.

| Metric | JSON Path | Definition | Interpretation |
|--------|-----------|------------|----------------|
| **Pearson r** | `insample.pearson_r` | Pearson correlation between score and 3Y excess return | Linear relationship strength. Sensitive to outliers. |
| **Spearman r** | `insample.spearman_r` | Spearman rank correlation between score and 3Y excess return | Rank-order relationship. More robust than Pearson. |
| **Mean IC** | `insample.mean_ic` | Mean of per-period cross-sectional Spearman correlations | Average predictive power per scoring date. The primary IS metric. |
| **IC IR** | `insample.ic_ir` | Mean IC / Std(IC) | Consistency of predictive signal. Higher = more stable across periods. |
| **IC Hit Rate** | `insample.ic_hit_rate` | % of scoring periods where IC > 0 | Reliability. 100% = positive signal in every single period. |
| **Decile Spread** | `insample.decile_spread` | Avg excess return of top decile minus avg excess return of bottom decile | Magnitude of separation between best and worst ranked locations. In percentage points. |
| **Quintile Table** | `insample.quintile_table` | 5-row table: quintile, avg_score, avg_excess_return, n, beat_median_rate | The core diagnostic. Must be monotonic (Q5 > Q4 > ... > Q1). |
| **Beat-Median Rate** | Within quintile table | % of locations in quintile whose excess return > 0 (i.e., beat state median) | Q5 should be well above 50%, Q1 well below. |
| **N with target** | `n_with_target` | Number of scored outcomes that have 3Y return data | Sample size for IS metrics. |

### Out-of-Sample Metrics

All OOS metrics come from `optimized_weights.json`, computed on held-out test periods the model never trained on.

| Metric | JSON Path | Definition | Interpretation |
|--------|-----------|------------|----------------|
| **OOS IC** | `summary.avg_test_ic` | Average Spearman IC across test windows | The headline OOS metric. Positive = real predictive signal. |
| **OOS Quintile Spread** | `summary.avg_test_quintile_spread` | Avg Q5 excess minus avg Q1 excess across test windows | Dollar-convertible measure of model value. In percentage points. |
| **OOS Hit Rate** | `summary.avg_test_hit_rate` | % of test scoring periods with IC > 0 | OOS reliability. |
| **Bootstrap Significant** | `summary.bootstrap_significant` | Whether 95% bootstrap CI for quintile spread excludes 0 | Statistical significance test. |
| **Bootstrap 95% CI** | `summary.bootstrap_ci` | [lower, upper] bounds on quintile spread | Uncertainty range. |
| **N Windows** | `summary.n_windows` | Number of walk-forward windows that produced results | Dynamically generated: 24-month train, 12-month test, 1-year slide from Jan 2020. Grows automatically as 3Y outcomes become available. Windows with < 20 test rows are skipped. |
| **N Test** | `summary.n_test` | Total test observations across all windows | OOS sample size. |

### Derived Metrics (Computed in Report)

These are calculated from the above. Show the formula in the report.

| Metric | Formula | Notes |
|--------|---------|-------|
| **IC Degradation** | `1 - (OOS IC / IS Mean IC)` | Both must use state benchmark. Flag >50% as WATCH, >70% as WARN. |
| **Annual Dollar Alpha** | `OOS quintile spread (pp) / 100 × median home value` | Cite median home value source and date. |
| **3Y Cumulative Dollar Alpha** | `median_home × ((1 + Q5_excess/100)^3 - (1 + Q1_excess/100)^3)` | Use OOS quintile table Q5 and Q1 avg excess values. |

### Target Variables

These are what the model is evaluated against. Critical to get right.

| Score Type | Target Column (IS validation) | Target Expression (Training) | Description |
|------------|------------------------------|------------------------------|-------------|
| HomeReady | `excess_state_3y` | `bo.excess_vs_state_3y` | 3Y appreciation CAGR minus state median 3Y appreciation CAGR |
| InvestorEdge | `excess_total_state_3y` | `bo.excess_vs_state_3y + (bo.rent_return_3y_cagr - bo.state_rent_return_3y_cagr)` | 3Y appreciation excess + 3Y rent excess, both vs state |
| InvestorEdge (fallback) | `excess_state_3y` | `bo.excess_vs_state_3y` | When rent data coverage < 5%, falls back to appreciation only |

### Feature Weights

From `optimized_weights.json` → `stable_features`.

| Field | Type | Meaning |
|-------|------|---------|
| `name` | string | Metric name (e.g., `median_days_on_market`) |
| `mean_coef` | float | Average elastic net coefficient across windows |
| `direction` | +1 or -1 | +1 = higher is better, -1 = lower is better |
| `weight` | float | Normalized weight (0-1, sums to 1.0 within score type) |

### Calibration Metrics

| Metric | JSON Path | Definition |
|--------|-----------|------------|
| **MAD** | `calibration.mean_absolute_deviation` | Mean absolute deviation between predicted percentile and actual return percentile across deciles. In percentage points. |
| **Decile Table** | `calibration.decile_calibration` | 10-row table: score_decile, predicted_percentile, actual_return_percentile, deviation |

### Time Stability

| Metric | JSON Path | Definition |
|--------|-----------|------------|
| **IC by Year** | `time_stability.ic_by_year` | Per-year mean IC values. PASS if > 0, FAIL if ≤ 0 (with ≥ 20 observations). |

## Robustness Thresholds

These are the pass/fail criteria used in Section 8 of the report.

| Test | Pass | Watch | Warn/Fail |
|------|------|-------|-----------|
| OOS IC | > 0 and bootstrap significant | > 0 but CI includes 0 | ≤ 0 |
| Bootstrap significance | 95% CI excludes 0 | — | CI includes 0 |
| IC hit rate | ≥ 75% | 50-74% | < 50% |
| Monotonic quintiles | Perfect or 1 adjacent swap | — | 2+ swaps |
| Feature stability | No sign flips, CV < 1.0 | — | Any sign flip or CV ≥ 1.0 |
| Time stability | IC > 0 every year (≥ 20 obs) | 1 year fails | 2+ years fail |
| IC degradation | < 50% | 50-70% | > 70% |
| Calibration MAD | < 15 pp | 15-20 pp | > 20 pp |

## Glossary

| Term | Definition |
|------|------------|
| **Alpha** | Excess return above a benchmark. In PropertyIQ: return above the state median. |
| **Beta** | Raw market return including regional trends. Not what the model predicts. |
| **CAGR** | Compound Annual Growth Rate. Annualized return over a multi-year period. |
| **Census Division** | One of 9 US Census geographic divisions. Used as secondary benchmark only. |
| **Excess return** | Location's CAGR minus its state's median CAGR for the same period. |
| **IC** | Information Coefficient. Cross-sectional Spearman rank correlation between score and subsequent excess return, computed per scoring period. |
| **IC IR** | Information Ratio of IC. Mean IC divided by standard deviation of IC. Measures consistency. |
| **OOS** | Out-of-sample. Metrics on data the model never trained on. |
| **IS** | In-sample. Metrics on all available data (includes training data). |
| **Quintile spread** | Average excess return of top quintile minus average excess return of bottom quintile. In percentage points. |
| **Walk-forward CV** | Train on period A, test on subsequent period B. No future data in training. |
| **ZHVI** | Zillow Home Value Index. Smoothed, repeat-sales home price estimate. |
| **ZORI** | Zillow Observed Rent Index. Smoothed rental price estimate. |
